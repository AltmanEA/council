# Glossary (fixtures copy)

**Escalation reason** (Причина эскалации) — The reason an issue is routed to the human operator. Values: `information-gap`, `irresolvable-conflict`, `risk-threshold-breach`, `timeout`.
**ConsensusVerdict.outcome** (Результат консенсус-вердикта) — The outcome value from a round of evaluation. Values: `consensus`, `conditional`, `no-consensus`, `blocked-escalation`.
**Escalation Protocol** (Протокол эскалации) — The rules governing when and how issues are escalated to the human operator.
**Consensus** (Консенсус) — All participants agree on a recommendation.
