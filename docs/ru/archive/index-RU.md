Эта папка является архивом устаревших документов проекта согласно конвенции Архив (`documentation-rules` §2.6, `documenter-service/index.md` §Архив). Она содержит документы, которые больше не обладают авторитетом, но остаются читаемыми, чтобы обоснование прошлых решений оставалось доступным.

Правила архива:

1. НЕ ВЫПОЛНЯЙТЕ, не реализуйте и не соблюдайте ничего в этой папке — архивированные документы помечены SUPERSEDED и описывают механизмы или дизайны, которые более не действуют.
2. НЕ ССЫЛАЙТЕСЬ на архивированные документы как на текущий авторитет; авторитетная спецификация любого концепта — его живой документ под `docs/en/` (см. `service-contract/index.md`, Content Precedence).
3. НЕ УДАЛЯЙТЕ архив; история git является путём восстановления, и эта папка — его читаемый надгробный маркер.
4. Архивированные документы доступны только для чтения в силу дисциплины (OP-1): правки отклоняются навыком Documentation Worker; попадания в архив отображаются на Карточке согласования в строке `Archive:`.
5. Механизм аудита (`tools/check_all.py`) исключает это дерево по префиксу пути; исключённые проверки здесь не являются сигналом дефекта.

Компоновка: по одной папке на архивированный документ id (`docs/en/archive/<id>/` с первичным `index.md`), русские зеркала под `docs/ru/archive/<id>/`.

Содержимое: `documenter-service/` — устаревший набор Документатора v0.x (guard: `documenter-service/index.md`).
