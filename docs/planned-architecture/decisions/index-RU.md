## Обзор

Пять обязательных архитектурных решений, принятых мультиролевым консиллиумом консенсусом трёх ролей: Архитектор, Специалист по надёжности и безопасности, Человеко-ориентированный дизайнер.

Самостоятельный ADR-документ, на который ссылались более ранние версии, больше не является частью набора документации. Идентификаторы остаются стабильными; их текущие определения:

| ID | Решение | Где применяется |
|----|---------|-----------------|
| ADR-001 | Структурные утверждения + тесты на основе свойств; без LLM в верификации безопасности | `layer-0.md` |
| ADR-002 | Ноль молчаливых значений по умолчанию; каждый параметр прослеживаем в манифесте сессии | `layer-1.md` |
| ADR-003 | Детерминированный поиск локализации ошибок; без сообщений, генерируемых LLM | `layer-2.md` |
| ADR-004 | Гибридные контрольные точки/возобновление (отложено до Фазы 2+) | Спецификация среды выполнения |
| ADR-005 | Цепочка миграции схемы — отложено до окончания MVP | `layer-2.md` |

D3 (Documenter как Supporting service) задокументирована в `../index.md` и `../../documenter-service/index.md`.
