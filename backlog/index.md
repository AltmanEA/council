## Ideas

**Scenario-driven role assignment.** Instead of fixed roles for every session, define reusable scenarios (e.g., "architectural review", "security audit") that specify which roles activate, their prompts, and the phase sequence. Each scenario is a recipe; roles are ingredients. Useful when the role set grows beyond 3–5 participants.
