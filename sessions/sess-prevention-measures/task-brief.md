Предыстория: sess-translate-automation (см. sessions/sess-translate-automation/) — автоматизация RU-перевода внедрена (ADR-012), контрольный прогон вскрыл 4 дефекта.

## Task Description

Контрольный прогон переводчика (`tools/local_translate.py`, документ scenario) вскрыл дефекты:
1. Ложные `[FAIL]`: табличные разделители и metadata-ключ `has_translation:` не были в `needs_skip` → ложный exit 4. Починено.
2. `enforce_glossary` кириллизировал идентификаторы: `no_consensus_budget` → `no_Консенсус_budget` (regex-граница слова без `_`). Починено. **Найди предсказывалась консилиумом прошлой сессии (Reliability), но не была конвертирована в защиту.**
3. Заголовки не переводились — противоречие трёх источников: код (E-005 skip `#`), конвенция существующих RU-файлов (`# Сценарии`), контракт SKILL.md («headings copied verbatim»). Починено: перевод + `restore_heading_prefix()`. Хвост: текст контракта SKILL.md всё ещё расходится с поведением — требует правки после Approve.
4. `--summary-json`/run log не писались при exit 4 (порядок кода). Починено.

Корневые причины: нет тестов переводчика вообще; «непереводимое» определяется прозой и разрозненными знаниями; предупреждения консилиумов не материализуются в артефакты; EN↔RU структурный дрейф проверяется агентом «глазами» (детерминистического инструмента нет — в `tools/` есть только manifest↔disk parity, `check_parity.py`).

## Предлагаемые меры (объект обсуждения)

- **A. Регрессионный корпус переводчика.** `tools/tests/` с mock-бэкендом (`TRANSLATE_BACKEND=mock`, канонизированные ответы), без GPU. Инварианты на фикстурах (scenario и др.): fail==0, заголовки переведены/префикс цел, inline-code и пути byte-identical, идентификаторы не тронуты, line-parity, структура таблиц/фенсов. Прогон из `tools/hooks/pre-commit` (block-режим при изменении `tools/local_translate*`).
- **B. `tools/check_drift.py` — структурный fingerprint EN↔RU.** Детерминированное сравнение: заголовки/иерархия, строки таблиц, фенсы, маркеры списков, число и идентичность inline-code-спанов, fingerprint метаданных. Заполняет дыру «EN↔RU дрейф глазами»; используется drift-audit-режимом skill'а; кандидаты в аудит-периметр §8 (детерминистика — tools, по образцу правил 1,2,4,6).
- **C. Единый источник правды «непереводимого».** `needs_skip` — единственный арбитр; `METADATA_KEYS` синхронизировать с парсером `docmeta.py` (общая константа/импорт); чек-лист при добавлении структурных типов.
- **D. Процессная норма: warning консилиума → тест-кейс.** Каждая finding high/critical из консилиумов материализуется в action item «тест, воспроизводящий failure mode». Где закрепить (AGENTS.md §6? §8? skill?) — вопрос.
- **E. Точечные страховки.** Unit-тест инварианта glossary-regex (не заменять внутри `[A-Za-z0-9_]`); правило «exit-коды не вставляются до блоков отчётности» (закрывается тестом A).

Приоритет авторов: A + B обязательны, C желательно, D — процессная норма, E — частные случаи A.
