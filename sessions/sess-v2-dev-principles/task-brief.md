## Session Goal

Принять два принципа разработки версии 2 Консилиума и зафиксировать их в новом документе `draft/v2-dev-principles.md`:

**П1. Разделение работы между кодом и ИИ-агентами (двухфазный принцип).**
Конечное состояние системы: «то, что можно сделать кодом, делается кодом» — детерминированные функции реализуются кодом. На период разработки: сначала делается самый простой вариант — инструкции для ИИ-агентов (промпт-контракты) вместе с кодом; только проверенные на реальной работе вещи переводятся в код. Т.е. ИИ-инструкция — это разрабатываемый, обкатываемый черновик будущей кодовой функции.

**П2. Отказ от жёстких сценариев; служебные агенты перед консилиумом.**
Не используются заранее записанные жёсткие сценарии проведения консилиума. Перед консилиумом запускаются служебные агенты. Точный список уточняется, но для начала два:
- **CA-1 Контекст-коллектор:** собирает информацию, необходимую для решения задачи консилиума, — формирует контекст для последующих агентов (ролей консилиума).
- **CA-2 Анализатор задачи:** анализирует задачу и определяет участников консилиума, т.е. формирует сценарий «на лету».
